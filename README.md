# WStore IPTV Panel - 100% Funcional

## 🎯 Sistema Completo de IPTV com M3U/M3U8 Licenciado

### ✨ Funcionalidades

- ✅ Dashboard Administrativo
- ✅ Login e Autenticação (JWT)
- ✅ Gestão de Revendedores
- ✅ Gestão de Clientes
- ✅ Planos e Créditos
- ✅ Ativação de Clientes
- ✅ M3U/M3U8 Gerado por Cliente
- ✅ Categorias de Canais, Filmes e Séries
- ✅ EPG (Guia de Programação)
- ✅ Logs de Acesso e Uso
- ✅ Branding WStore
- ✅ Responsivo (Web, App, SmartTV)
- ✅ Painel de Suporte e Tickets
- ✅ Relatórios e Estatísticas

### 🏗️ Stack Tecnológico

**Frontend:**
- Next.js 14+
- React 18+
- Tailwind CSS
- TypeScript
- Axios

**Backend:**
- NestJS
- PostgreSQL
- Redis
- JWT Auth
- Socket.io (Chat em tempo real)

**DevOps:**
- Docker & Docker Compose
- Nginx
- SSL/TLS

```
wstore-iptv-panel/

└── docs/
```

### 🚀 Quick Start

```bash
# Clone o repositório
git clone https://github.com/williamlayla123/wstore-iptv-panel.git
cd wstore-iptv-panel

# Instale dependências
npm install

# Configure o .env
cp .env.example .env

# Inicie com Docker
docker-compose up -d

# Ou desenvolvimento local
npm run dev
```
